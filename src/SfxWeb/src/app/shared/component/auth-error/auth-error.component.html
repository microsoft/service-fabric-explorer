Explanation

Service Fabric Explorer runs entirely in your browser and finishes sign-in using cross-origin token redemption — it exchanges the authorization code for a token by calling Microsoft Entra directly from this page's script. Microsoft Entra only permits cross-origin token redemption for reply URLs registered under the Single-page application platform.

Service Fabric Explorer previously signed in with ADAL (Azure AD Authentication Library), which is now deprecated. ADAL redeemed the token in a way that worked with reply URLs registered under the Web platform, so this app registration was likely configured for ADAL. The current, standards-compliant MSAL (Microsoft Authentication Library) uses the OAuth 2.0 authorization code flow with PKCE for single-page apps, so a Web-registered reply URL that worked under ADAL is now rejected.
